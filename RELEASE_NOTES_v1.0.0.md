# Loki MD v1.0.0

Loki MD is a clean macOS front end for Calibre's ebook conversion engine.

## Features

- Convert EPUB, MOBI, PDF, AZW3, DOCX and TXT formats
- Convert multiple files in one batch
- Show total progress and current-file progress
- Choose a custom output folder
- Use Calibre's conversion engine without launching its legacy GUI
- Run on both Apple Silicon and Intel Macs with one universal DMG

## Install

1. Download `Loki MD-1.0.0-universal.dmg` below.
2. Open the DMG and drag `Loki MD.app` to `Applications`.
3. Launch Loki MD from Applications.

This release is unsigned. On the first launch, macOS may require right-clicking the app and selecting `Open`, or approving it from `System Settings > Privacy & Security > Open Anyway`.
