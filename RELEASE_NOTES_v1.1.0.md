# Loki电子书转换器 v1.1.0

## What's new

- Added a Windows x64 installer.
- The Windows installer checks for Calibre and installs the official Calibre MSI when needed.
- Windows conversions run with the console window hidden.
- Added a Windows application icon.
- macOS support remains available in the previous `v1.0.0` release.

## Download

- macOS: download the universal `.dmg` from the previous `v1.0.0` release, open it, and drag `Loki电子书转换器.app` to `Applications`.
- Windows: download `Loki电子书转换器 Setup 1.1.0.exe` from this release and run the installer. The installer may ask for administrator permission because Calibre is installed as a prerequisite.

The Windows installer is currently unsigned, so Windows SmartScreen may require an explicit confirmation. The bundled Calibre component is the official Calibre Windows MSI and remains subject to the GNU GPL v3 license. See [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
